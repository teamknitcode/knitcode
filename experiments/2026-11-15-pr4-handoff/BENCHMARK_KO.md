# 동적 보조 분석 1차 실험 결과

> 호출 관계 보강의 기본 후보는 `--calls-only`로 유지한다. 전체 추적은 필요할 때 선택한다. 호출 중심 추적도 일반 실행 대비 비용은 상당하다.

## 실험 조건

- macOS ARM64 / Python 3.12.2, 임시 가상환경 사용
- PR 수정 커밋 `5d5c63d` + 이번에 발견한 가상환경 경로 수정 적용
- Requests 커밋 `3c7baaa05ab4aa49cc819ce3a819d260de19c157`
- 대상: 동적 `getattr` 호출 예제(1,000회), Requests의 `test_structures.py`·`test_hooks.py`(27개 테스트)
- 일반 실행 / 호출·타입 수집 / 줄·opcode까지 전체 추적을 각 3회, 순서를 회차마다 바꿔 실행
- pytest 자동 플러그인 로딩 비활성화. 선택한 테스트는 네트워크를 사용하지 않음
- 시간은 프로세스 시작·수집 초기화·기록 저장·자식 보고서 취합을 포함한 전체 명령 시간. 정적 분석 및 저장 후 비교 시간은 제외

## 성능 결과 — 중앙값

| 대상 | 모드 | 시간 | 일반 실행 대비 | 최대 RSS | 실행 기록 크기 |

| 동적 호출 예제 | 일반 | 0.015초 | 1배 | 12.4 MiB | — |

Requests에서 calls-only는 전체 추적보다 약 **54% 짧고**, 기록 크기는 약 **88% 작았다**. 메모리는 macOS `/usr/bin/time -l`의 최대 RSS이며 동시 실행 프로세스 메모리의 합계가 아니다.

## 정적 분석 보완 효과

| 대상 | 정적·실행 일치 관계 | 실행에서 추가 발견 | 연결 불가 실행 간선 |
|---|---:|---:|---:|
| 동적 호출 예제 | 2 | 1 | 0 |
| Requests 27개 | 11 | 17 | 8 |

관계 집계 기준은 **호출자 + 호출 대상 + 호출 줄**이다. 모듈·클래스 본문 진입은 위 일치·추가 집계에서 제외한다. 두 추적 모드의 일치·추가 관계 집계는 같았다.

- 예제에서는 정적 분석이 놓친 `dispatch → EmailWorker.run`을 추가로 관찰했다. 실제 사용한 구현체에 실행 근거를 붙일 수 있음을 확인했다.
- Requests의 추가 관계 17개 중 **16개는 테스트 함수에서 출발**했다. 제품 코드 호출자는 `requests.hooks.dispatch_hook → tests.test_hooks.hook` 1개이며, 테스트가 전달한 콜백이다.
- 따라서 17개를 모두 일반 사용자 실행의 누락으로 해석하면 안 된다. 테스트 코드 포함 여부와 함수 관계의 성격을 별도로 표시해야 한다.
- 연결 불가 항목은 추가 분석 대상이며, 정적 분석 오류나 정상 호출로 자동 분류하지 않는다.

## 실험 중 발견·수정한 문제

`--python`에 지정한 가상환경 실행 파일의 심볼릭 링크를 `resolve()`하면 기반 Python이 실행돼 가상환경 패키지를 찾지 못했다. 경로를 절대화하되 링크를 유지하도록 수정했다.
가상환경에만 설치된 모듈을 읽는 회귀 검사를 추가했고, 동적 분석 검사 **33개가 통과**했다.

전체 pytest는 다음 설정으로 **569 passed, 7 skipped, 41 subtests passed**를 확인했다. 단순 실행은 기존 중복 테스트 이름으로 수집 오류가 발생하므로 수집 방식과 원본 검사 경로를 명시했다.

```bash
PYTHONPATH=tests/jse_original /path/to/pytest-python -m pytest tests -q --import-mode=importlib
```

이전 문서의 스레드 회귀 검사·내부 README가 현재 작업 트리에서 제거된 상태도 확인했다. 이번 변경에서는 해당 차이를 덮어쓰지 않았으며, 가상환경 수정 패치에는 포함하지 않았다. PR 반영 전 최종 차이를 확인해야 한다.

## 판단과 다음 단계

1. **호출 중심 모드를 기본 후보로 유지:** 비용은 줄지만 무비용은 아니므로 선택 테스트 실행으로 제공
2. **두 수정 사항을 PR에 반영:** 기존 opcode 수정 패치와 이번 가상환경 수정 패치를 함께 검토
3. **관계 분류 정리:** 제품 코드·테스트 호출자·콜백·연결 불가를 구분
4. **시각화 연결:** 정적 그래프를 유지하고 실행 근거를 겹쳐 표시

이번 결과는 짧은 테스트 27개와 작은 예제에 대한 초기 측정이다. 프로세스 시작과 전체 소스 스캔 비용이 배수에 크게 반영된다. 전체 프로젝트·장시간 실행 비용, DynaPyt 대비 성능, 전체 정적 정확도로 일반화하지 않는다. 원격 push·merge는 하지 않았다.
